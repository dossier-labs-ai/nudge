## Policy / Mechanism Boundary

### Policy contract

- Source: user's Nudge proposal and explicit v0 simplification in this thread.
- Only declared numeric feedback determines reward; missing feedback is absent,
  not zero. A complete replacement report wins by insertion order.
- No outcome computation, automatic learning schedule, or certified promotion.
- No app integration, production operations, deployment, or publishing.

### Mechanism contract

- One SQLite file, append-only decisions/feedback/snapshots, cached features.
- Per-action Gaussian linear regression, clipped exponential tilt, baseline mix.
- Pin answerer identity; choice/action/feedback/model changes cannot silently
  reuse incompatible logs. Reward changes are explicit new fitted snapshots.
- External inference goes through TensorZero with explicit configuration.

### Boundary tests

- Exact cold start, drift, feedback validation/corrections, snapshot provenance.
- Training-only proposer examples, selection split, failure atomicity,
  concurrent asks, schema/protocol validation, and gateway HTTP edge tests.
